# 今日校园风格模拟器 V2（iPhone PWA）

这是一个独立的校园生活演示网页，可通过 iPhone Safari 添加到主屏幕。它不是今日校园官方 App，不连接学校服务器。

## 部署
在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch，Branch 选 main，Folder 选 /(root)，保存。发布后访问 https://mayi87587.github.io/campus-simulator/ 。

## 功能
首页、消息、课程表、成绩、请假记录、校园卡展示、考试安排、失物招领示例、个人资料编辑。数据仅保存在本机浏览器。

## 限制
不提供真实学校认证、成绩查询、考勤、请假审批、支付或门禁功能。请勿输入真实密码或敏感信息。
